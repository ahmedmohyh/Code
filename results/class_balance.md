# Class Balance per Label Column

BIRAFFE2 provides six independent Flow label columns: three game levels
(GEQ-1, GEQ-2, GEQ-3) measured with two questionnaire versions each
(GEQ-2013 and GEQ-2018). Balance must be checked separately for each
column, because each one is a distinct binary classification target.

| Label Column | Median | Low n | High n | Total | Low % | High % | Balance |
|--------------|--------|-------|--------|-------|-------|--------|---------|
| GEQ-1-FLOW-2013 | 2.000 | 50 | 53 | 103 | 48.5 | 51.5 | balanced |
| GEQ-1-FLOW-2018 | 2.000 | 50 | 53 | 103 | 48.5 | 51.5 | balanced |
| GEQ-2-FLOW-2013 | 2.000 | 45 | 56 | 101 | 44.6 | 55.4 | slight imbalance |
| GEQ-2-FLOW-2018 | 2.000 | 45 | 56 | 101 | 44.6 | 55.4 | slight imbalance |
| GEQ-3-FLOW-2013 | 1.200 | 41 | 46 | 87 | 47.1 | 52.9 | slight imbalance |
| GEQ-3-FLOW-2018 | 1.200 | 41 | 46 | 87 | 47.1 | 52.9 | slight imbalance |

*Low = score < median; High = score >= median. Median computed over all available values in the column.*
